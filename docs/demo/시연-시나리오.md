# 시연 시나리오 (12/1 최종 발표, 녹화 약 3분)

시연은 실시간이 아니라 핵심 시나리오 하나를 녹화해 보여 준다(PM 결정, 2026-11-27). 이 문서는 녹화 순서와 화면에서 보일 값, 말할 문장을 정한다.
P0 흐름(2026-11-28 실서버 화면 리허설 확인)에 P1 네 가지(사진으로 찾기·플랜 B·날씨·공유, #80~#83)를 넣어 3분으로 다시 짰다.
P1 값은 2026-11-28 dev `cf8b5f2` 에서 API 로 확인했고(사진 찾기는 실제 사진 6장), 같은 날 실서버 화면으로 9장면을 리허설해 녹화했다
(`pinandfill_demo_3min.mp4`, 화면은 아래 '리허설에서 본 것' 참고). 그 리허설은 TMAP 키를 켠 채였다. **녹화는 TMAP 키를 끄고 한다**(준비 2).
경로는 TMAP 무료 한도(하루 10건) 때문에 대부분 '추정' 이동시간이다.

## 시나리오 입력값

- 날짜: **2026-12-05 (토)** 당일, 하루 일정 **10:00–21:00**, 이동 **대중교통**
- 꼭 갈 곳(이 순서로 담는다):

| 장소 | 담는 방법 | 시간 |
| --- | --- | --- |
| 태종대 → '태종대유원지' | 장소 검색 | 10:00–11:00 고정 |

### 시연용 사진(사진으로 찾기)

- 파일: Wikimedia Commons `File:Gwangalli Beach and bridge.jpg` — **퍼블릭 도메인**이라 출처 표기 의무가 없다(영상 끝 자막에 'Wikimedia Commons'만 적어도 된다).
- 녹화 기기(데스크톱 Chrome 기기 모드)에 미리 내려받아 둔다. 2026-11-28 확인: 광안리해수욕장 **확신도 98%**, 약 2초.
- 다른 사진을 쓰려면 직접 찍은 사진이나 CC0·퍼블릭 도메인 사진을 쓴다. CC BY·CC BY-SA 사진은 영상에 작성자·라이선스를 표기해야 한다.
- 같은 날 확인한 다른 사진: 감천문화마을 95%, 오륙도 스카이워크 93%, 용두산 공원(부산타워) 97%, 해동용궁사 97%, 서울 경복궁(목록 밖) '찾지 못함'.

## 녹화 전 준비

1. **최신 dev** 로 받는다(`git pull`). 새 의존성이 있으니 `cd backend && uv sync`. `data/crowd/` 에 생활인구·승하차·연결표 3개 파일이 있어야 한다.
2. **키**(`backend/.env`, 값은 공유하지 않는다)
   - `KAKAO_REST_API_KEY`: 장소 검색(필수).
   - `ANTHROPIC_API_KEY`: 사진으로 찾기(필수). 없으면 사진 찾기가 '준비되지 않았어요'(503). 호출마다 비용이 들므로 Anthropic Console 에서 지출 한도를 걸어 둔다. 같은 IP 에서 1분에 6번까지만 보낼 수 있다.
   - `DATA04_SERVICE_KEY`: 생활인구, 그리고 기상청 예보(같은 공공데이터포털 계정이면 `KMA_SERVICE_KEY` 없이 이 키로 호출된다). 없으면 예보 배지가 숨는다.
   - `TMAP_API_KEY` 는 **녹화 때 빈 값으로 둔다**(`TMAP_API_KEY=`). 일부 구간만 TMAP 실측이 되면 추정 구간과 섞여
     용두산 18:40, 경유지 오륙도 '+0분 우회', 카드마다 '공급자 이동시간이며…' 칩처럼 이 문서와 다른 값이 나온다(11/28 리허설).
   - `frontend/.env.local`: `VITE_KAKAO_MAP_JS_KEY`(지도, 필수). 허용 도메인에 `http://localhost:5173`.
   - `GEMINI_API_KEY` 는 없어도 된다. 한 줄 해석은 규칙으로, 경유지 이유는 규칙 문구로 나온다.
3. **서버**(녹화 중에 다시 켜지 않는다. `DATABASE_URL` 이 없으면 여행·공유 링크가 메모리에만 있어 재시작하면 사라진다)

   ```bash
   cd backend && uv run uvicorn app.main:app --port 8000
   cd frontend && npm run dev            # http://localhost:5173
   ```

   `npm run dev` 가 'Port 5173 is in use' 로 5174 에 뜨면 다른 앱이 5173 을 쓰고 있다. 카카오 지도 키는 `localhost:5173` 만
   허용하므로 지도가 안 뜬다(11/28 리허설). 5173 을 쓰는 앱을 끄고 다시 켠다.

4. **브라우저**: Chrome 개발자 도구 기기 모드 **390 × 844**(휴대폰 세로). 사이트 데이터(localStorage·sessionStorage)를 지운다.
   플랜 B 알림은 여행·장소마다 이 탭에서 한 번 뜬다. 녹화 때 코스를 새로 만들면 다시 뜬다.
5. 녹화 직전 한 번 끝까지 리허설한다. TMAP 키가 있으면 리허설에서 한도(10건)를 쓰므로 녹화 때 '추정'으로 나와도 정상이다.

## 진행 순서와 대본

P0 장면(1·3·5~8)의 화면 값은 11/28 리허설(TMAP 키 없이)에서 확인한 값이고, P1 값(2 사진·3 날씨·4·9)은 API 와 11/28 화면 리허설 값이다.
이동시간은 '추정'이라 1~2분 다를 수 있다. 날씨는 녹화하는 날의 예보에 따라 다르다.

### 1. 여행 시작 (15초)

- 한 줄 입력에 `12/5 당일 대중교통` → **해석**. 날짜·이동이 채워진다. 하루 일정 끝을 **21:00** 으로 바꾼다.
- 대본: "여행 조건은 한 줄로 쓰면 항목으로 풀어 줍니다."

### 2. 꼭 갈 곳 담기 (30초)

- 위 표 순서대로 담는다: 태종대유원지 검색 **담기** → 광안리는 **사진으로 찾기** → 용두산공원·부산시립미술관 검색 **담기**(검색은 빨리 감기).
- 사진으로 찾기: 시연용 사진 고르기 → 후보 '광안리해수욕장', "확신도 97% · 관광지"(API 98%, 화면은 사진을 줄여 보내 97%) → **담기**('✓ 담김') → **돌아가기**.
- 태종대유원지·광안리·미술관은 **시간 정하기** 로 시각을 넣는다. 용두산은 그대로 둔다.
- 대본: "이름을 몰라도 사진 한 장이면 됩니다. AI가 공공 데이터에 있는 장소 중에서만 고르고, 확신이 낮으면 찾지 못했다고 말해요.
  사진은 위치 정보를 지우고 보내며 저장하지 않습니다. 시간을 정한 곳은 고정돼서 어떤 계산에서도 움직이지 않아요."

### 3. 코스 만들기 (25초)

- **코스 만들기**. 타임라인 화면:

| 시각 | 장소 | 카드 | 예상 혼잡 |
| --- | --- | --- | --- |
| 10:00–11:00 | 태종대유원지 🔒 | 실선 | 붐빔(신뢰 낮음) |
| 13:00–14:00 | 광안리해수욕장 🔒 | 실선 | 붐빔(신뢰 중간) |
| 17:00–18:00 | 부산시립미술관 🔒 | 실선 | 붐빔(신뢰 중간) |
| 18:53–19:38 | 용두산 공원 | 실선 | 붐빔(신뢰 중간) |

- 카드마다 날씨 배지: 12/5는 녹화일 기준 단기예보(약 3일) 밖이라 **'예보(일 단위)'** 로 나온다. 11/28 18시 발표 기준 네 카드 모두 '예보(일 단위) 흐림 · 강수 30% · 11~17°'(11/28 화면).
  일 단위 예보는 12시 전 카드는 오전, 뒤 카드는 오후 값이라 날에 따라 카드끼리 다를 수 있다. 녹화일이 가까워 단기예보에 들어오면 '예보 …'(시간 단위)로 바뀌고, 비 예보면 플랜 B 가 '비 예보가 있어요'로 바뀐다.
- 대본: "고정한 세 곳은 정한 시각 그대로예요. 시간을 정하지 않은 용두산은 14시대가 예상 '매우 붐빔'이라 저녁으로 옮겼어요.
  저녁도 '붐빔'이라 다음처럼 다른 방법도 보여 줍니다.
  날씨는 기상청 예보이고, 사흘 뒤까지는 시간 단위, 그 뒤는 일 단위로 보여 줍니다."

### 4. 플랜 B (25초)

- 타임라인 위 알림 "**용두산 공원 18:53** 예상 붐빔이에요. 다른 방법도 볼까요?" → **플랜 B 보기**.
- 시트 "용두산 공원 플랜 B", "지금 시각은 예상 붐빔이에요. 고르기 전에는 일정을 바꾸지 않아요.", "시각·이동시간은 추정이에요…"
  - 그대로 가기: 18:53–19:38, 지금 일정 그대로
  - 순서 바꾸기: 고를 수 없음 — "고정 시각과 하루 일정을 지키면서 덜 붐비게 되는 순서가 없어요."
  - 대체 장소: **흰여울문화마을** 18:56–20:26, 예상 여유(신뢰 낮음), 영업시간 충돌 없음, 이동 +3분(추정, API).
    11/28 화면 리허설(TMAP 키 켬)에서는 '이동 +24분(추정)'이었다. TMAP 키를 끄면 API 값과 같아진다.
- **그대로 두기** 를 누른다(일정이 바뀌지 않는다).
- 대본: "다음 장소가 붐비거나 야외인데 비 예보가 생기면 한 번 알려 드리고, 그대로 가기·순서 바꾸기·대체 장소 세 가지를 비교해 보여 줍니다.
  고정 시각을 못 지키는 안은 내지 않고, 고르기 전에는 아무것도 바꾸지 않아요."

### 5. 경유지 추천 (30초)

- 태종대유원지와 광안리 사이 **사이에 들를 곳 추천받기** → 시트 제목 "태종대유원지 → 광안리해수욕장 사이".
- 기본 **우회는 최대 15분** 그대로 후보 **오륙도 스카이워크 +14분 우회**, '넣어도 그대로: 광안리해수욕장 13:00, 부산시립미술관 17:00'.
- **넣기** → 알림 "일정에 넣었어요: 오륙도 스카이워크…", 점선 카드가 강조된다. 광안리 13:00 은 그대로다.
- 대본: "핵심지 사이 빈 시간을 우회가 적고 덜 붐비는 곳으로 채웁니다. 직접 고른 곳은 실선, 추천으로 채운 곳은 점선이에요."

### 6. 장소 상세 (15초)

- 용두산 공원 카드의 **장소 상세 보기** → 시간대별 예상 혼잡(토요일 13–17시 '매우 붐빔', 19시 '보통'), 신뢰도 중간, 기준 시각, 출처. **근거 보기** 를 펼친다.
- 대본: "예상 혼잡은 생활인구와 지하철 승하차 통계로 계산한 예상이고, 근거와 기준 시각을 같이 보여 줍니다."

### 7. 지도 (10초)

- 뒤로 → **지도로 보기**. 마커 5개와 방문 순서 선. 목록에서 광안리를 누르면 지도가 그 마커로 간다.
- 대본: "선은 방문 순서만 잇고 실제 도로 경로는 아니라고 밝혀 둡니다."

### 8. 되돌리기 (10초)

- 타임라인으로 돌아와 오른쪽 위 **되돌리기 아이콘(↶)** → 오륙도가 빠지고 "직전 편집을 되돌렸어요".
- 대본: "방금 한 편집은 한 단계 되돌릴 수 있어요."

### 9. 공유 (20초)

- 오른쪽 위 **공유 아이콘** → 시트 "일정 공유"(아래 "12월 12일까지 열려요.", 여행 끝나고 7일) → **링크 복사** → "복사했어요".
- **같은 탭** 주소창에 붙여 넣어 연다(새 탭은 기기 모드가 풀린다) → "공유받은 일정 · 보기 전용". 편집·추천·되돌리기 버튼이 없다.
- 대본: "동행자에게는 링크만 보내면 됩니다. 받은 사람은 보기만 할 수 있고, 링크는 여행이 끝나고 일주일 뒤에 닫혀요."

## 문제가 생기면

| 상황 | 대처 |
| --- | --- |
| 용두산이 14:45 에 들어감 | `data/crowd/` 파일이 없거나 백엔드를 그 전에 켰다. 파일을 확인하고 백엔드를 다시 켠 뒤 처음부터 |
| 사진으로 찾기가 '준비되지 않았어요' | `ANTHROPIC_API_KEY` 확인 후 백엔드 재시작. 급하면 광안리를 장소 검색으로 담는다 |
| 사진으로 '찾지 못했어요' | 시연용 사진이 맞는지 확인. 1분에 6번을 넘겼으면 잠시 기다린다 |
| 플랜 B 알림이 안 뜸 | 이 여행에서 이미 닫았다('괜찮아요'·'플랜 B 보기'), 또는 용두산 혼잡이 '붐빔·신뢰 중간' 미만(`data/crowd` 확인). 용두산 카드의 **플랜 B** 버튼을 누른다 |
| 경유지 오륙도가 '+0분 우회' | TMAP 키가 켜져 기준 구간만 실측이다. `TMAP_API_KEY=` 로 끄고 백엔드를 다시 켠다 |
| 예보 배지가 없음 | 기상청 키(`DATA04_SERVICE_KEY`·`KMA_SERVICE_KEY`) 확인. 배지 없이 진행해도 된다 |
| 경유지 후보가 없음 | 우회를 30분으로 바꾼다. TMAP 실측 값이면 후보가 달라질 수 있다 |
| 지도가 안 뜸 | 프런트가 5173 이 아닌 포트(5174 등)에 떴거나, 지도 JS 키 허용 도메인에 `localhost:5173` 이 없다. 아니면 7번 장면을 뺀다 |
| 한 줄 해석이 실패 | 날짜·시간·이동을 직접 고른다 |
| '다시 선택 필요' 카드 | 카카오 장소를 담은 뒤 새로고침하면 이름이 사라진다(D6). 새로고침하지 않는다 |
| 공유 화면이 '링크가 없거나 만료' | 백엔드를 재시작했다(메모리 저장). 공유 시트를 다시 열어 새 링크를 만든다 |
